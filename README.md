# Tmuxmod

Tmux layout helpers for launching workspaces with yazi, opencode, and lazygit.
Includes multi-project workflows for applying layouts across directories.

## Functions
- `tcl`: Create a three-pane layout for the current directory.
- `tclm`: Apply `tcl` layout to each subdirectory.
- `tclf`: Apply `tcl` layout to selected subdirectories.
- `tal`: Create a two-pane layout with yazi and opencode.
- `talm`: Apply `tal` layout to each subdirectory.
- `talf`: Apply `tal` layout to selected subdirectories.
- `tn`: Open new tmux windows for selected subdirectories.
